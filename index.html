pnpm 10 + uv — defensas por default

npm postinstall = vector #1

La cadena de suministro npm/PyPI es el vector de malware mas explotado en 2024-2026 (typosquatting, postinstall scripts, takeover de mantenedores). OSSFIA exige package managers que no corren scripts arbitrarios por default.

📦
pnpm 10 (Node / TypeScript)
  • • NO corre lifecycle scripts (postinstall/preinstall) por default
  • • onlyBuiltDependencies allowlist explicita
  • • minimumReleaseAge defensa contra typosquatting reciente
  • • Lockfile estricto + content-addressable storage
🐍
uv (Python)
  • • Resolver hermetico reproducible

  • • 10-100x mas rapido que pip → menos drift por timeouts
