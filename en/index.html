FAB Fleet Methodology · v10.21 → v10.23

Empirical case study at scale

Measured field data, not theory: 117 agents coordinated across 11 fleets in ~2 calendar days on a regulated EU mid-market AI platform. 99% success rate, 126 squash-merges to main, ~1,995 files delivered, ~$545 in agent cost.

What changed in v10.21

Mandatory re-audit tier — every fleet ships with its own independent verified_by auditor that re-scores with evidence (file:line + grep + harness re-run). Caught real over-claims in every wave. Security score went 38.9 → 79.0 over 7 measured waves, monotonically.

What changed in v10.23 (ADR-030)

Cross-fleet pipelining — the N+1 producer wave runs concurrent with N's re_audit when the file partitions are disjoint. Compresses wall-clock further while preserving the audit gate. The methodology learns from its own evidence and applies the learning.

The API contract before the code. OSSFIA Spectral blocks PRs without a spec in CI — Postman and Stoplight live outside the repo and cannot do that. We are complementary, not a competitor: they generate (mocks, SDKs, docs); we govern (DLP, bounded contexts, Dual-Rail deprecation).

📋

13 custom Spectral rules

Unique in the market — these rules require knowledge of your capability_map and data_classification.

Supply chain hardening · v10.22

pnpm + uv as the OSSFIA standard

Not an aesthetic preference. The defaults of npm and pip are known attack vectors — recent malware chains exploit them. The OSSFIA standard closes those defaults by construction.

📦
pnpm 10 — JS/TS
  • No lifecycle scripts by default — postinstall is the #1 npm malware vector. pnpm 10 only runs scripts from the onlyBuiltDependencies allowlist.
  • minimumReleaseAge ~1440 min — defense against recent typosquatting: pnpm refuses versions published less than N minutes ago.
  • Content-addressed store + strict symlinks — eliminates phantom dependencies. Only declared packages can be imported.
  • --frozen-lockfile in CI — fails if pnpm-lock.yaml doesn't match package.json. No silent drift.
🐍
uv — Python
  • Hermetic resolver — deterministic resolution, no implicit network calls during install.
  • Hash-pinned uv.lock — every artifact hashed; uv sync --frozen verifies hashes before installation.
  • Speed as side-effect — 10-100× faster than pip, but the point is the security model, not the benchmark.
  • Standard for the whole ecosystem — init-project.sh scaffolds it, init-brownfield.sh adds it additively.
